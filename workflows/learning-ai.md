## Start from the pain on your desk

If you do not yet know what an agent is for, start from the work already in front of you. Take the step that hurts: the refund answer you rewrite every week, the screen that throws, the links you keep losing. Do that job with an agent beside you.

That pain is the curriculum. Making this workflow cheaper and faster is the on-ramp. A plan to earn money from the tools can wait until one real job is cheaper than it was last month.

The job teaches the words you actually need: what a deliverable is, where the file went, which sentence was invented. [How to talk to AI](talking-to-ai.md) is the work order for that job. Use it the same week.

A finished page you can reread tomorrow is the lesson.

## A vault, and an agent beside it

Follow a few practitioners on X whose posts show finished work. This page keeps no roster. A roster goes stale, and a stranger's timeline will not do your job. When a post changes the task you will do tomorrow, keep it.

Keep it in a Markdown vault. Obsidian is a comfortable reader for that folder. Any editor that opens Markdown is enough. Folder roles are the [Mac-first IPARAG skeleton](mac-first-obsidian-iparag.md): Inbox for the capture, Projects for the goal you are shipping, Knowledge for the note you would still want next month. PARA credit for the four classic roles is in [Resources](resources.md).

A second brain, here, is that vault plus an agent with a small clerical job.

You capture. A kept post becomes a note:

- One idea, and a title a search can find
- The source link
- One line in your words: why you kept it, and which goal it touches
- A wikilink when a second note should be found with the first

The agent classifies the note into a folder, interprets the claim in a few lines, and suggests where it meets a project you already have. You decide. [Human notes stay as written](principles.md). The agent appends. Your sentence stays. A claim in the note points at the source link. The piece you admired stays at its URL. The vault holds your line, the link, and a short quotation only when you need the author's phrasing.

Write the notes in the shape you want them found, and say that shape in the work order. One idea. A title. The link. The wikilink. Try it on a small folder. Then open the note and see what the agent actually read and wrote. [Cross-file sync](cross-file-sync.md) is the longer version, once the folder is no longer a handful of files. A second system can wait until the first note has a home.

## A clip becomes a note

The slow part is the capture. A post you meant to keep dies in a bookmark list. A post that lands as a Markdown file can be classified.

Grok Bot is one place that path is real. A bookmark or a clip can come back as material for the vault, and an agent can classify it, interpret it, and suggest a home. That is the edge worth using. It is hygiene for a reading trail you already chose to keep.

Pasting a link into Inbox is the same habit. The folder is the point. The product is one door into the folder.

The goal still comes from the pain on your desk. Screens and account steps stay in the product's own docs. Any agent that can read a folder can classify a note once the note exists. [Principles](principles.md) still hold: a public page stays public, and a private capture stays in the local vault, off the remote.

If filing captures should be one desk's whole job, write it as a [Soft CoS](soft-cos.md) desk. The job is one sentence: file captures and suggest a folder. The anti-jobs sit beside it: do not rewrite the note, do not publish, do not start the project. The same chat as the goal is also fine. The folder matters more than which product opened it.

## A week that is enough

1. Name one painful step you can finish in a few days.
2. Send a work order: deliverable, done-when, and the rules.
3. When a word or a missing file stops you, read that one page in the table above.
4. When a post earns a keep, put a short Markdown note in Inbox. Ask an agent to suggest the folder. Leave your line as written.

Repeat the week. The course, the fleet pages, and a larger vault are what the repeats grow into.
