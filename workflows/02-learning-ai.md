## Start from the pain on your desk

If you do not yet know what an agent is for, start from the work already in front of you. Take the step that hurts: the refund answer you rewrite every week, the screen that throws, the links you keep losing. Do that job with an agent beside you.

That pain is where you start. Make this step cheaper than it was last month. A plan to earn money from the tools can wait until then.

The job teaches what you actually need: what you asked for, where the file went, which sentence was invented. [How to talk to AI](01-talking-to-ai.md) is how to say that job in a message. Use it the same week.

A finished page you can reread tomorrow is the lesson.

## A vault, and an agent beside it

When something you read changes what you will do tomorrow, keep it.

Keep it in a Markdown vault. [Why a Markdown vault](03-why-a-markdown-vault.md) is why that folder is the memory, what it changes, and when the chat is still enough. Obsidian is a comfortable reader for that folder. Any editor that opens Markdown is enough. Folder roles are the [Mac-first IPARAG skeleton](14-mac-first-obsidian-iparag.md): Inbox for the capture, Projects for the thing you are finishing, Knowledge for the note you would still want next month. PARA credit for the four classic roles is in [Resources](15-resources.md).

That vault, plus an agent with a small filing job, is enough.

You capture. What you kept becomes a note:

- One idea, and a title a search can find
- The source link
- One line in your words: why you kept it, and which job it touches
- A wikilink when a second note should be found with the first

The agent suggests a folder, writes a few lines on what the note is saying, and points at a project you already have. You decide. [Human notes stay as written](11-principles.md). The agent appends. Your sentence stays. A claim in the note points at the source link. The piece you admired stays at its URL. The vault holds your line, the link, and a short quotation only when you need the author's phrasing.

Write the notes in the shape you want them found, and say that shape in the message. One idea. A title. The link. The wikilink. Try it on a small folder. Then open the note and see what the agent actually read and wrote. [Cross-file sync](34-cross-file-sync.md) is the longer version, once the folder is no longer a handful of files. A second system can wait until the first note has a home.

## A clip becomes a note

The slow part is the capture. A post you meant to keep dies in a bookmark list. A post that lands as a Markdown file can be filed.

Grok Bot is one place that path is real. A bookmark or a clip can come back as material for the vault, and an agent can file it, say what it claims in a few lines, and suggest a home. That is the part worth using. It keeps a reading trail you already chose.

Pasting a link into Inbox is the same habit. The folder is the point. The product is one door into the folder.

The job still comes from the pain on your desk. Screens and account steps stay in the product's own docs. Any agent that can read a folder can file a note once the note exists. [Principles](11-principles.md) still hold: a public page stays public, and a private capture stays in the local vault, off the remote.

If filing captures should be one helper's whole job, write it the way [Soft CoS](12-soft-cos.md) writes a desk. One sentence: file captures and suggest a folder. Next to it, what it does not do: do not rewrite the note, do not publish, do not start the project. The same chat as the job is also fine. The folder matters more than which product opened it.

## A week that is enough

1. Name one painful step you can finish in a few days.
2. Send the ask the way [How to talk to AI](01-talking-to-ai.md) describes: what you want, what finished looks like, what not to touch, and how you will know it worked.
3. When a word or a missing file stops you, read that one page in the table above.
4. When a post earns a keep, put a short Markdown note in Inbox. Ask an agent to suggest the folder. Leave your line as written.

Repeat the week. The course, the fleet pages, and a larger vault are what the repeats grow into.
